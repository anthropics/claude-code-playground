# Security Policy

This repository contains sample code, demos and configuration examples that are provided as-is, without support. It is not an official Anthropic product.

## Reporting security issues

The security of our systems and user data is Anthropic's top priority. We appreciate the work of security researchers acting in good faith in identifying and reporting potential vulnerabilities.

Our security program is managed on HackerOne and we ask that any validated vulnerability be reported through their [submission form](https://hackerone.com/4f1f16ba-10d3-4d09-9ecc-c721aad90f24/embedded_submissions/new) rather than in a public issue.

Our Bug Bounty Program guidelines are on our [HackerOne program page](https://hackerone.com/anthropic).
