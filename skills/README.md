# Skills

Reusable skills we use ourselves that are not part of the official plugin marketplace. One folder per skill, containing the skill itself (`SKILL.md` plus any supporting files) and a README based on [`_template/README.md`](../_template/README.md).

Official example skills and the Agent Skills spec live in [anthropics/skills](https://github.com/anthropics/skills); installable plugins live in [anthropics/claude-plugins-official](https://github.com/anthropics/claude-plugins-official). Skills here are shared as-is and may move to one of those repositories later.
