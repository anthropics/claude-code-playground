# Demos

Art-of-the-possible demos: the result plus the story of how it was made. These are not starter templates to fork (see [anthropics/claude-quickstarts](https://github.com/anthropics/claude-quickstarts) for those); the point is to show what Claude did and how we prompted it.

One folder per demo. Each follows [`_template/README.md`](../_template/README.md), including the model used (publicly available models only), the prompts, and what did not work.
